# Little Piano maintenance

Published content lives in `frontend-game/games/little_piano/`. No build step or external runtime library. `songs.js` contains typed MIDI pitches (C4–C6) and beat lengths. The two copyrighted titles are explicitly limited to brief opening phrases; do not silently expand them into complete scores. Other pieces are single-note teaching arrangements of traditional/classical melodies, plus an original black-key exercise.

Audio: Alexander Holm's Salamander Grand Piano v3, CC BY 3.0. Nine stereo samples distributed by Tone.js, nearest-sample transposition at most one semitone, 24 simultaneous voices maximum, soft key release. Original downloads and SHA-256 hashes are in `art/little-piano/`; rerun `python3 scripts/little-piano/prepare-samples.py` to recreate web samples. Retain the sample LICENSE and the in-game credits when distributing.

English voice: use existing `scripts/english-learning/generate-speech.py` with `--lines scripts/little-piano/speech-lines.json`, `--out frontend-game/games/little_piano/audio`, `--raw-dir art/little-piano/voice-raw`, and the server's protected `--env-file`. Do not put credentials into the repository. The scene uses CosyVoice 3.5 Plus with the Pip profile. Validate through `scripts/game-voices/verify-speech.py`. Store generation manifest outside the public audio folder in `art/little-piano/voice-manifest.json`.

Keyboard: 15 white + 10 black keys; landscape single row, portrait two octave rows. Free play supports chords and glissando. Guided play advances only on a new, correct press, never on a held key or timeout. Hear note is an example, not an advance. Auto mode uses Web Audio clock scheduling, three speeds, pause/restart; changing song cancels old scheduled notes. Blur/pagehide/hidden pause auto and release keys. No automatic foreground resume. Parent homepage pre-unlocks audio and disables background music through the `little_piano` entry in `ENGLISH_GAMES`; direct links also unlock on touchend/pointerup.

Tests: `tests/little-piano.cjs` checks all 219 guided notes across eight songs, 25 pitches, repeated-note release, chords, wrong taps, audio playback/pause/completion, keyboard layouts and language. `tests/little-piano-integration.cjs` checks homepage entry/return, live audio RMS, parent context, quiet BGM, and download-failure retry. Tests use Playwright Chromium/WebKit with installed explicit executable paths, `PIANO_BASE` for the site and `PIANO_TEST_OUT` for artifacts; analytics requests are blocked. WebKit multi-touch uses independently dispatched PointerEvents; Chromium uses CDP touch input. These tests emulate iPad viewports; they do not claim physical-device latency measurement.

Before publication, use an isolated copy and the static publish lock; compare the exact current baseline, back up existing files and install only the manifest. Home card count becomes 40; the new card follows Dino Dig (7th), preserving the previously pinned first six. Age badge 1+ describes the simplest free-touch mode, not mastery of guided songs.
